🎭 JO BAND OFFICIAL SITE
Partout où ça bouge, JO BAND est là.

Ce site web professionnel est la vitrine officielle du groupe artistique JO BAND, basé à Lomé, Togo. Il présente les prestations du groupe (Humour, Animation, Événementiel), permet une prise de contact rapide, et intègre plusieurs fonctionnalités dynamiques pour engager la communauté.

🚀 Caractéristiques

Design : Interface premium en bleu marine et or, animations fluides, mode sombre géré nativement.
Bilingue : Support natif Français / Anglais.
SEO Ready : Données structurées (JSON-LD), Open Graph optimisé, favicon, sitemap.
Compatible réseaux sociaux : Détection et bandeau d'ouverture externe pour TikTok, Facebook, Instagram, Snapchat et autres navigateurs intégrés.
PWA : Installable sur l'écran d'accueil, avec Service Worker et gestion de cache automatique.

🤖 ALICE — Assistante virtuelle
FAQ locale instantanée + cascade de secours vers 3 IA (Groq, Gemini, Mistral).
Synthèse vocale (Edge TTS) avec préchargement audio pour une lecture fluide.
Journalisation automatique des questions sans réponse locale, pour amélioration continue de la FAQ.

⭐ Fonctionnalités dynamiques
Témoignages clients : soumission publique, modération manuelle, carrousel automatique.
Calendrier d'événements : gestion via Firebase Console, disparition automatique des événements passés.
Newsletter : cascade de secours (Formspree → Web3Forms → WhatsApp) + synchronisation Brevo pour l'envoi de campagnes.
Flux YouTube dynamique : détection automatique Shorts vs vidéos classiques.
Notifications push et abonnement WhatsApp officiel.

🛠️ Technologies
HTML5 / CSS3
JavaScript (Vanilla)
Firebase / Firestore
Vercel (hébergement + fonctions serverless)
Font Awesome
Google Fonts (Plus Jakarta Sans)
