🎭 JO BAND OFFICIAL SITE
Partout où ça bouge, JO BAND est là.
Ce site web professionnel est la vitrine officielle du groupe artistique JO BAND, basé à Lomé, Togo. Il présente les prestations du groupe (Humour, Animation, Événementiel) et permet une prise de contact rapide.
🚀 Caractéristiques
Performance : Site statique ultra-léger (Single File HTML).
Design Premium : Glassmorphism, animations fluides et mode sombre.
Bilingue : Support natif Français / Anglais.
SEO Ready : Optimisé pour les moteurs de recherche.
